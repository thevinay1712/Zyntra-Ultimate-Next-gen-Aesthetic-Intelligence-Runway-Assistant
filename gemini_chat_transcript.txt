Choosing the Right Architecture

For a 140-mark VR/AR subject (40 internal + 100 sem-end), evaluators almost always prefer a native Unity mobile app (APK) over a web-only demo because it proves you used real AR SDKs (ARCore/ARKit) and 3D pipelines.

Approach	Tech Stack	Best For	Effort
Native AR App (Recommended)	Blender + Unity + AR Foundation (ARCore/ARKit)	Highest marks; smooth face/body tracking on Android/iOS	Medium
Hybrid Integration	Existing Zyntra App + Unity as a Library (UaaL)	Keeping Zyntra's UI/backend while launching Unity for the AR camera	High
WebAR Fallback	Blender + Three.js / MindAR (or Unity WebGL)	If you don't have an ARCore-supported phone for the live demo	Low–Medium
Step-by-Step Build Roadmap
1
Lock a Smart MVP Scope
Avoid full cloth-simulation physics

Real-time 3D cloth draping (like a flowing shirt) is notoriously buggy on mobile AR. Instead, structure your demo around 2–3 high-reliability categories:

Head/Face Accessories (Easiest & Most Impressive): Sunglasses, caps, hats, or earrings using AR Face Tracking.

Apparel / Upper Body: A 3D jacket, hoodie, or t-shirt anchored to torso landmarks (using ARKit Body Tracking on iOS, or the MediaPipe Unity Plugin on Android), OR a 3D Virtual Mannequin mode where users adjust body measurements and rotate the garment in AR space.

2
Build & Optimize 3D Assets in Blender
Keep models under 15k–20k triangles

You don't need to sculpt everything from scratch. You can model simple items (like glasses or a cap) or customize free base meshes (from Sketchfab/Poly Haven) in Blender:

Apply PBR materials (Base Color, Roughness, Metallic) so fabrics and metals look realistic.

Set the Origin Point accurately (e.g., bridge of the nose for glasses, center of the collar for shirts)—this is where Unity will anchor the object.

Export as .fbx (with Embed Textures enabled) or .glb.

3
Configure Unity + AR Foundation
Use Unity 2022.3 LTS or Unity 6

Install AR Foundation and ARCore XR Plugin (Android) or ARKit XR Plugin (iOS) via the Unity Package Manager.

Set up a basic scene with an AR Session and XR Origin.

Import your Blender .fbx models into Assets/Models and convert each one into a Prefab.

4
Implement Tracking & Try-On Controls

Attach an AR Face Manager (for face accessories) or MediaPipe Pose/Body Tracking (for clothing/wrists) to your XR Origin.

Write a lightweight C# AccessorySwitcher script connected to a bottom UI carousel so the user can tap to swap between 3D prefabs and change garment colors/textures in real time.

Enable AR Light Estimation so the 3D apparel matches the real-world room lighting.

5
Package for Internal (40) & Sem-End (100) Grading

For the 40-mark Internal: Show your Blender .blend files (wireframe + UV unwrapping), your Unity scene hierarchy, and a working APK with at least 2 swappable accessories.

For the 100-mark Sem-End: Add a "Capture/Save Look" screenshot button, a size/scale slider, and an architectural diagram showing the Blender → Unity → ARCore pipeline. Always keep a recorded demo video on your phone as a backup in case the exam room lighting disrupts tracking.

If I ask Antigravity to do all this stuff and finish the project completely, will it do ?

Antigravity can handle about 70–80% of this project, including writing all the code and even controlling Blender and Unity directly—provided you connect its plugins/MCP servers and feed it one phase at a time. It will not finish the entire project cleanly from a single giant prompt.

What Antigravity Will Do vs. What You Must Do
Task	Can Antigravity Do It?	Reality Check
React + Node Integration (TryOn.jsx, react-unity-webgl, API wiring)	Yes (100%)	Its strongest area. It can read your existing Zyntra repo, install packages, and wire up the Unity WebGL bridge cleanly.
Unity C# Scripting & Scene Setup	Yes (with Unity Plugin / MCP)	Using Unity's official Antigravity plugin (unity-agent-plugin) and Unity MCP Server, Antigravity can write AccessoryManager.cs, attach components, and inspect your active scene.
Blender Tweaks & Exporting	Partially (with Blender MCP)	With a Blender MCP server connected, it can fix origin points, apply transforms, tweak materials, and export .fbx/.glb files. However, AI-generated 3D models from scratch often look rough—download free base meshes for glasses/caps and let Antigravity help adjust and export them.
Project Creation, APK Builds & AR Testing	No (Manual)	You must install Unity Hub, create the initial 3D URP project, install AR Foundation/ARCore, build the .apk, and test face-tracking alignment on your actual phone.
How to Set Up Antigravity So It Can Actually Help

Connect Unity to Antigravity: Open Antigravity, go to Customizations → Plugins, search for Unity, and click Add (or run agy plugin install [https://github.com/Unity-Technologies/unity-agent-plugin](https://github.com/Unity-Technologies/unity-agent-plugin) in the terminal). Enable the Unity MCP Server inside Unity's Project Settings so the agent can interact with your open Unity Editor.

Connect Blender (Optional): If you want Antigravity to automate exports from VirtualTryOn/templates/, install a Blender MCP add-on and add it to Antigravity's mcp_config.json.
